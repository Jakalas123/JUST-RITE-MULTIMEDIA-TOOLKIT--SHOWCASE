# JUST RITE MULTIMEDIA TOOLKIT V3

**A cross-platform multimedia toolkit for Windows and Linux.**

JUST RITE MULTIMEDIA TOOLKIT V3 is an actively developed desktop application bringing a range of multimedia tools together in one project.

## About the project

The project has separate Windows and Linux versions, with platform-specific dependencies, launch procedures and build processes.

### Platform support

- **Windows:** Windows 10 and later.
- **Linux:** Developed with AnduinOS 2.0.5 as the target environment.

## Multimedia capabilities

The project includes dedicated modules for:

- Video processing and conversion
- Audio processing
- Image tools
- Multimedia downloading
- Metadata handling
- FFmpeg-related tools
- Validation and supporting utilities

## Project status

JUST RITE MULTIMEDIA TOOLKIT V3 is under active development. Features, compatibility and packaging continue to be reviewed and improved.
