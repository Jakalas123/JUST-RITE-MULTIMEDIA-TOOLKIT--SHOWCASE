# JUST RITE MULTIMEDIA TOOLKIT V3

**A cross-platform multimedia toolkit for Windows and Linux.**

JUST RITE MULTIMEDIA TOOLKIT V3 is an actively developed desktop application bringing a range of multimedia tools together in one project.

## About the project

The project has separate Windows and Linux versions, with platform-specific dependencies, launch procedures and build processes.

### Platform support

- **Windows:** Windows 10 and later.
- **Linux:** Developed with AnduinOS 2.0.5 as the target environment.

## Multimedia capabilities

The project includes dedicated modules for:

- Video processing and conversion
- Audio processing
- Image tools
- Multimedia downloading
- Metadata handling
- FFmpeg-based multimedia processing
- Smooth Streaming media preparation and indexing
- Validation and supporting utilities

### Smooth Streaming

Smooth Streaming support remains part of the project source. The workflow uses FFmpeg's ISMV output together with the ISM Indexer helper to generate Smooth Streaming manifest files, including `.ism` and `.ismc`.

The Linux_Newest engineering workstream has successfully exercised ISMV generation and ISM Indexer manifest generation, including a combined video-and-audio manifest test. These are component-level functional results; validation of the final packaged Linux desktop application and installer is still pending. This distinction is intentional so that the showcase does not imply that final packaging has already been verified.

## Project status

JUST RITE MULTIMEDIA TOOLKIT V3 is under active development. Features, compatibility and packaging continue to be reviewed and improved.

The project maintains separate Windows and Linux build workstreams. Platform-specific packaging and runtime verification are tracked independently.
